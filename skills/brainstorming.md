# Brainstorming

## Goal

Generate a diverse set of useful possibilities.

## Techniques

Use techniques such as:

- divergent thinking
- constraint inversion
- analogy
- combination
- "what if" scenarios
- extreme versions
- removing assumptions
- changing the target user
- changing the environment
- reversing cause and effect
- simplifying the problem
- deliberately making the idea absurd

## Diversity requirement

Avoid producing ten variations of the same idea.

When generating multiple ideas, deliberately vary:

- approach
- audience
- scale
- technology
- business model
- assumptions
- level of risk

## Output

For large brainstorms, group ideas into categories.

Aim for useful diversity rather than maximum quantity.
